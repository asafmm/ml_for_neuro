01

Linear vs. logistic regression

Everything so far assumed y was a number: firing rate, wage, memory score.
Plenty of the questions we actually ask are not: male or female, which of three diagnoses.
When y is a category, the task is classification (instead of regression).

Let's stay with two categories, which is a pretty common scenario.
For more than two categories the ideas are similar, with one extra set of coefficients per extra category.
We get to that in the Multinomial logistic tab.

First, let's turn the two categories into numbers we can compute with:

yi = 0control 1MDD

Why not use linear regression for classification?

Say we simply want to use linear regression to predict who is a patient.
Below, you can see a synthetic connectivity score from a resting-state scan, and whether that subject met criteria for MDD.
Fit a straight line to the 0/1 outcome and read it as a probability:

A straight line through a 0/1 outcome

A probability below zero? When the model predicts a "probability" below 0, or above 1, it shows its structure is problematic. The straight line is unrestricted, and doesn't know that y only takes two values, so it extrapolates beyond these values.
We need a model whose output is a probability by construction.

The logistic function

We want a model that takes any number and returns something between 0 and 1 (a probability).
One common solution is the logistic function.
The linear part stays exactly as it was, but we put it through a function that squashes it between 0 and 1.

Let's build that function ourselves.
The line has exactly two problems: it goes below 0, and it goes above 1.
We fix them one at a time.

To have real numbers to look at, we pick β0 = 0.4 and β1 = 1.8 by hand for now.
We get to where the real values come from at the end of this tab.

02
0 < eβ0+β1X < +∞
First problem: below 0.
We need something that turns any number into a positive one.
The exponential does exactly that: e to any power is positive.
For example, e−2 = 0.14, e0 = 1 and e2 = 7.39.
It also keeps the order: a higher line still gives a higher number.
Below 0 is gone. Above 1 is still there, and now it grows even faster.
03
0 < eβ0+β1X 1 + eβ0+β1X < 1
Second problem: above 1.
We divide that positive number by itself plus one.
The bottom is always bigger than the top, so the fraction stays below 1.
Both are positive, so it stays above 0.
We can read it as a share: 3 out of 3 + 1 is 0.75, and 100 out of 100 + 1 is 0.99.
The bigger the number, the closer to 1.
We will see in the next tab what the 1 stands for.
This plot zooms in on the vertical axis, because the band is now all that is left.

The fraction gets close to 0 and close to 1, but it never reaches either one.
A line of exactly 0 lands on exactly one half. We will use that in a moment.

That fraction is the logistic function.
Whatever the line does, the output is a probability by construction.
We call it p(X): the probability that y = 1 for a subject with this X.

p(X) = eβ0+β1X 1 + eβ0+β1X

Other functions could also squash a line between 0 and 1.
We use this one because it is easy to reverse, which is what the next tab is about.

The two coefficients do different jobs, and it is worth separating them:

  • β1 sets how steep the transition from 0 to 1 is. A bigger value means a sharper switch between classes.
  • β0 slides the whole curve left or right.
    The halfway point is where the line equals 0, at X = −β0/β1.
What the two coefficients do
drag them and watch the curve

Push β1 negative and the curve runs the other way: high scores become evidence against the diagnosis. Set it to zero and the model gives every subject the same probability.

Where the coefficients come from

To estimate the coefficients, we use maximum likelihood:
we pick the β values under which the labels we observed are the most probable.
In practice we maximize the log of the likelihood.

There is no closed-form solution for this maximization problem.
The β sit inside an exponential, so unlike the slope formula from simple linear regression, the answer has to be found by iterating (efficiently) through possible values.

Key idea

This is still a linear model. β0 + β1X is still in there, all we added was a function around it, so that whatever it returns comes out as a probability.

02

The logit

The linear part in logistic regression

The S-shaped curve of the logistic function is hard to reason about.
But if we take the equation for p(X) and divide it by 1 − p(X), we get:

p(X)1 − p(X)  =  eβ0+β1X

That ratio is the odds: how many times more likely the positive diagnosis is than the negative one.
If p(X) = 0.8, the odds are 0.8/0.2 = 4, or four to one.
This is what the 1 in the logistic function stands for: the positive diagnosis gets a share of 4 against the negative one's 1, and 4 out of 4 + 1 is 0.8.
Take the log of both sides and you get a linear function:

log p(X)1 − p(X)  =  β0 + β1X

The left side is the logit, or the log odds.
So logistic regression is a linear function of the log odds!
In other words, if we add one more unit of X, it adds β1 to the log odds.

Both panels below are the same model. Only the vertical axis differs.

Probability on the left, log odds on the right
one model, two scales

Probability. Bounded, and the effect of X changes along the axis: very steep in the middle, and almost flat at either end.

Log odds. Unbounded, and the effect of X is one constant slope. Same β1 as the panel on the left.

So what does β1 actually mean?

In linear regression the answer was easy: one more unit of X adds β1 to y.

Here the same question has three answers, depending on which scale we ask it on. Take one step along X, from wherever we happen to be standing, and:

  • on the logit scale the step always adds β1: it's linear.
  • on the odds scale it multiplies by eβ1.
  • on the probability scale it adds an amount that depends on where we started.

Move the step along the axis below and see for yourself.

One step in X, read on three scales
slide the step along and see what stays constant

Log odds. The step is the same height anywhere on the axis.

Probability. The same step is biggest in the middle of X and shrinks toward both ends.

β1 does not represent a change in probability. It is a change in log odds, and the same β1 adds a different amount of probability depending on where we start. Moving a subject from p = 0.50 to 0.62 and from p = 0.95 to 0.97 can both be the same step in β1.
Summary

Logistic regression is still a linear model. It is linear in the log odds, not in the probability. Just like linear regression, we can still add multiple predictors, powers, dummies, and interactions.

03

The decision boundary

In linear regression, we had a line (or a plane) that fitted the data.
In logistic regression we get the same line, but as a decision boundary that separates the classes.

The model still returns a probability for every subject. To turn that into a decision we need a rule, usually: decide it is MDD when p ≥ 0.5 (more on that 0.5 value later).

One predictor: the boundary is a point

Let's start with the single predictor from the previous tabs.
Here is the logistic function again, with the rule drawn on it:

One predictor, one point on the axis
move the coefficients: the boundary follows the crossing

The strip along the bottom is the same probability, drawn as a colour instead of a height.
We will need it in the next plot, where both axes are taken by predictors.

The decision changes at one place on the X axis, right under the point where the curve crosses 0.5.
Where is that? p = 0.5 means odds of 0.5/0.5 = 1, and log 1 = 0, so the switch happens where the linear part is zero:

β0 + β1X  =  0

That equation has one solution, a single value of X.
With one predictor, the decision boundary is this one point:

X = − β0 β1

Two predictors: the boundary is a line

Let's take an example with two predictors:

log p1 − p  =  β0 + β1x1 + β2x2

The rule is the same, so the switch again happens where the linear part is zero:

β0 + β1x1 + β2x2  =  0

That is the equation of a straight line! Rearranged the way we would plot it:

x2 = − β0 + β1x1 β2

This line is the decision boundary: every subject on one side is marked as a patient, every subject on the other a control.
Logistic regression is thus a linear classifier.

Here are two synthetic connectivity scores, from two different networks, with the patient/control binary outcome.
We set every third control and every third patient aside as a test set.
We fit on the training subjects only, and check the result on the test subjects:

Two predictors, one straight boundary
move the coefficients and watch the line, then fit it

Three things we learn from this plot:

  • β0 slides the boundary without turning it. That's the intercept.
  • β1 and β2 together set its angle. Only their ratio matters for the angle: doubling both keeps it the same.
    Doubling all three coefficients leaves the boundary exactly where it is.
  • We can see the steepness in the fitted probability shading: it is the same steepness we saw in the 1D sigmoid, just in a higher dimension.
Decision boundaries can be curved! If the two groups are separated by a circle rather than a line, we can add x12, x22 and x1x2 as columns. This will make the boundary nonlinear, but the model stays linear in its coefficients.

With the three new columns, the model becomes:

log p1 − p  =  β0 + β1x1 + β2x2 + β3x12 + β4x22 + β5x1x2

The boundary is still where this equals 0, but now that can be a circle, or any other curve of this shape.

04

Multinomial logistic regression

So far y had two categories.
What if it has three, say control, MDD and schizophrenia (SCZ)?
We write the number of categories as K, so here K = 3.

With two categories, p was the probability of MDD and 1 − p that of control.
So the logit already compared MDD against control:

log p1 − p  =  log pMDDpcontrol  =  β0 + β1X

That is one line, with one set of coefficients.
And control was already our baseline, the category we compare against.
To add SCZ, we keep the baseline and add a second line, with its own coefficients:

log pMDDpcontrol  =  βMDD,0 + βMDD,1X log pSCZpcontrol  =  βSCZ,0 + βSCZ,1X

In general, K categories give us K − 1 sets of coefficients.
Class 2 had the same count: K categories needed K − 1 dummy variables.

As before, we undo the log to get back to probabilities:

pMDD = eMDD line1 + eMDD line + eSCZ line pSCZ = eSCZ line1 + eMDD line + eSCZ line pcontrol = 11 + eMDD line + eSCZ line

In the first tab we read the logistic function as a share: 3 out of 3 + 1.
Here the sum has one more share.
MDD gets eMDD line, its odds against control, and control gets 1, its odds against itself.
SCZ gets eSCZ line, its odds against control.
For example, 3 out of 3 + 2 + 1 = 3/6 = 1/2.
Each probability is its own share out of the total, so the three add up to 1.

Here is a model with coefficients we picked by hand.
The top plot shows the two lines and the flat baseline.
The bottom plot shows the three probabilities they give:

Two lines against a baseline, three probabilities
move a coefficient, then switch the baseline

No coefficients of its own. Its line stays flat at 0.

To get predictions, at each X we predict the category with the highest probability.

Now switch the baseline.
Every coefficient changes in the top plot.
But the bottom plot stays exactly the same, because the relations stay the same.
The baseline is our choice: it changes what the coefficients compare, not what the model predicts.

So a coefficient only has a meaning together with its baseline.
With the starting values, βMDD,1 = 1.0 against control, and −1.5 against SCZ.
One more unit of X raises the log odds of MDD against control, and lowers them against SCZ.
Both are true of the same model.

Key idea

K categories, one baseline, K − 1 sets of coefficients. Each set compares one category with the baseline. A different baseline gives different coefficients, and the same probabilities.

05

Error types and metrics

The model returns a probability.
But a decision is a class, so somewhere we have to pick a threshold for the probability, where everything above it will be classified as a patient.

p = 0.5 is the obvious choice, but it is not necessarily the right one.

Once we threshold, every subject lands in one of four boxes, and the two kinds of mistake are not the same mistake:

acc = 1n nΣi=1 𝕀(yi = yi)

Accuracy counts all four boxes as though they were interchangeable.
Here is the problem: even with balanced groups, accuracy cannot tell a missed patient from a false alarm, and those have very different consequences.

Move the threshold, move the errors

Drag the threshold to 0 and we call everyone a patient: every patient found, every control alarmed. Drag it to 1 and the reverse. Everything useful happens in between.

Four numbers worth knowing

Each one divides a box by a row or a column of the table above, and each answers a different question:

  • Sensitivity, or recall: of the patients, how many did we find? Divides by the patient row. This is the one that matters when missing a case is dangerous.
  • Specificity: of the controls, how many did we correctly identify? Divides by the control row.
  • Precision: of those we flagged, how many really were patients? Divides by the flagged column.
  • F1: the harmonic mean of precision and recall, for when we want one number and accuracy will not do.

Every threshold at once: the ROC curve

Each of those four measures was computed at one threshold. Move the threshold and they all change, so any of them alone describes just one arbitrary threshold.

The ROC curve shows the whole set. Slide the threshold from 1 down to 0, and at every stop plot the pair we care about:

  • up the vertical axis, sensitivity: the share of patients we caught;
  • along the horizontal axis, 1 − specificity: the share of controls we false-alarmed.

Each threshold gives one point, and together the points make the curve.

Two corners are fixed.
At a threshold of 1 we flag nobody, so we catch no patients and alarm no controls: the bottom left.
At a threshold of 0 we flag everybody, catching every patient and alarming every control: the top right.

The panel below puts the two side by side. On the left, the same 400 subjects drawn as two distributions, one per class, with everything the threshold flags shaded in. On the right, the curve.

Squeezing the curve into one number

To summarize this entire curve, we use the area under the curve, the AUC.

A straight diagonal means AUC = 0.5. A curve that goes straight up and then straight across will have AUC = 1.

Another interpretation is this: pick one patient and one control at random, and AUC is the probability the model gives the patient the higher score. An AUC of 0.85 says it gets that right 85% of the time. A coin gets it right 50% of the time.

AUC = P( score of a random patient > score of a random control )
Examine and report several metrics. Sensitivity of 0.92 is meaningless without saying where we threshold, because we can always buy sensitivity with specificity by moving the cut. Pick the metric based on what's interesting for the research or application: sensitivity, precision, F1, or AUC.
06

The KNN classifier

Class 2 used nearest neighbours for regression: find the K closest training points and average their y.
For classification, we use the same idea: find the K closest points and take a vote.

p(Y=j | X=x0) = 1K Σi ∈ N0 𝕀(yi = j)

The fraction of the neighbourhood belonging to class j, used as a probability. Whichever class wins the vote is the prediction.

The difference from simple logistic regression is that the KNN decision boundary can take any shape:

Two boundaries on the same data

The dashed line is the Bayes boundary: where the true probability is exactly one half. It is the ground truth, the rule the data was simulated from.

At K = 1 the boundary breaks into small patches that separate the training points perfectly.
Raising K smooths it toward the truth, creating a more continuous boundary.
But smoothing too much is also bad!

Glossary

Everything introduced today, on top of the glossaries from classes 1 to 3.

classification
Supervised learning where y is a category rather than a number.
logistic function
ez/(1+ez). Takes any number and returns one strictly between 0 and 1.
odds
p/(1−p). How many times more likely the outcome is than its absence.
logit
log(p/(1−p)), the log odds. The scale on which logistic regression is a straight line.
odds ratio
eβ1. What the odds are multiplied by for one more unit of X.
likelihood
The probability of the data we collected, read as a function of the coefficients.
log-likelihood
Its log, which turns the product into a sum. What the optimiser actually maximises.
maximum
likelihood
Choosing the coefficients that make the observed data most probable.
no closed form
The score equations cannot be solved algebraically, so the fit is found by iterating.
perfect separation
Some value of X splits the classes cleanly, so the likelihood has no maximum and the coefficients diverge.
multinomial
logistic regression
Logistic regression for more than two categories. K categories give K − 1 sets of coefficients, one for each category except the baseline.
baseline category
The category the others are compared against. A different baseline gives different coefficients and the same probabilities.
threshold
The probability above which we call a case positive. A decision we make, not one the model makes.
confusion matrix
The four counts: true and false positives, true and false negatives.
sensitivity
(recall)
Of the true positives, the fraction we found. TP/(TP+FN).
specificity
Of the true negatives, the fraction we left alone. TN/(TN+FP).
precision
Of those we flagged, the fraction that were real. TP/(TP+FP). Depends on prevalence.
F1
Harmonic mean of precision and recall, when one number is wanted.
ROC curve
Sensitivity against 1 − specificity, traced across every threshold.
AUC
Area under that curve. The chance a random positive outranks a random negative.
decision boundary
The set of points where the prediction flips from one class to another.
Bayes boundary
Where the true probability is exactly one half. The best boundary any classifier could draw.
KNN classifier
Predict the class by majority vote among the K nearest training points.
